# 셀프 아이스크림 가게 (Self Ice Cream Shop)

셀프어쿠스틱 스톱모션 영상을 게임으로 만든 웹 빌드입니다. 휴대폰은 가로 화면으로 돌려서 플레이하세요.

- v6.2 (최신): 첫 화면 하리, 돈통 다시, 장비 3단계부터 비싸게, 허름한 가게에서 시작 + 가게 꾸미기 0~4단계, 7일차부터 장비가 필요해짐
- v6.1: 4일차부터 손님 2명씩, 의자(하트 천천히 줄기 3단계), 가격 조정, 결과 화면 "광고 보고 코인 2배"(웹은 테스트 광고 창)
- v6: 장비 성장(손 스쿱 → 자동 스쿱 5단계, 냉동고 = 장사 시간 + 통마다 재고·품절·완판, 녹는 얼음 게이지, 맨 앞 손님 하트), 1일차 손 스쿱 튜토리얼, 버벅임 수정(렌더 보간·90Hz·정적 층), 스톱모션 끔
- v5.1: 튜토리얼 말풍선 흔들림 수정, 통 테두리 한 겹, 주문 그림에 콘·컵 전체, 초반 손님 빨라짐, 구매 축하·새 물건 반짝임, 산 장식이 보이고 누르면 반응
- v5: 휴대폰 가독성 새 배치(손님·주문·통·아이템 크게), 스쿱이 콘·컵 안으로, 새 배경
- v4: 화면 겹침·태블릿 잘림 수정, 하루 시작 로딩 개선, 저장 불가 경고, 영어 문법 수정
- v3: 오류 사냥 반영 (저장 덮어쓰기 방지, 90/120Hz 화면 선명도, 튜토리얼·화면 겹침 수정)
- v2: 스쿱 쌓기·스쿱 도구 애니메이션·직접 퍼기·드래그 전달·어린이 터치 크기 개선
- v1: 첫 번째 플레이 가능 버전
